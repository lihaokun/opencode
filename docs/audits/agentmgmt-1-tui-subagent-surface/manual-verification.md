## 0. 前置

- **关闭自动更新**：启动前 `export OPENCODE_DISABLE_AUTOUPDATE=1`（或配置文件设
  `"autoupdate": false`）——否则 beta 可能被自动更新替换，验证结果作废
- 一个**有 subagent 记录**的会话：在该会话里让模型跑一次 `agent` 工具委派即可
  （例如"委派一个 explore 数一下 src 下文件数"）。子会话出现后回主会话。
- 若要可控的子会话数据（可选，等价于自动化里验证过的种子配方）：
  1. 隔离目录：`XDG_DATA_HOME=/tmp/t/data opencode serve --port 4919`
  2. `curl -X POST localhost:4919/session -d '{"title":"root"}' -H 'content-type: application/json'`
  3. `bun -e` 向 `$XDG_DATA_HOME/opencode/opencode-local.db` 的 `session` 表插子行：
     复制根行的 `project_id/directory/version`，设 `parent_id`、`metadata='{"agentName":"alpha"}'`、`agent='explore'`
  4. `GET /session` 应能看到子行（此形状已验证与 `subagentListMembers` 输入一致）

| #   | 步骤                                                                                     | 预期                                                                                                          |
| --- | ---------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| 2.1 | 任意会话（输入框**空**、光标在末尾），按一次 `down`                                       | 弹出 **Agents** 列表（无历史时一次就弹；有历史时先翻历史、回到空输入后再按一次弹）                            |
| 2.2 | 观察列表内容                                                                              | 全树成员：**Main 行打头**（root，描述含其 agent 类型）、直属 subagent、孙子向右缩进；每行 = 名字（无则类型/占位）；名称后有 muted 工作简述（标题剥离 `(@type subagent)`，Main 不加）；描述 = 类型 · 状态（idle/busy/retry）·（当前行）current；**当前会话行带 `current` 标记且打开时预选中**；**最右侧 = token 消耗（如 `12.3k tok`）· 时长** |
| 2.3 | 列表中选中另一会话回车                                                                    | 跳转到该会话（含 retry 弹窗逻辑）；选 **Main** 回根会话                                                       |

| 2.5 | 光标不在输入框末尾时按 `down`                                                             | 单行输入或光标在末行：跳到文本末尾，不弹列表；多行输入且光标不在末行：移动到下一行，同样不弹                  |
| 2.6 | 列表打开后按 `esc`                                                                        | 关闭列表、无残留；再按 `down` 可再次打开                                                                      |
| 2.7 | 列表打开后按 `up`/`down`/输入文字                                                         | 按键归列表（DialogSelect 既有行为回归）：上下移动选择、输入即过滤                                             |
| 2.8 | 导航删除回归：按 `up`、`left`、`right`、`<leader>down`；观察子会话视图 footer             | 四键均无导航行为；footer 不再显示 Parent/Prev/Next 按钮，左侧信息（名称/序号/token/开销）保留                 |
| 2.9 | 有 subagent 的会话，观察 assistant 消息尾部提示                                           | 提示为 `<down> view agents`（不再是 "view subagents"）                                                        |
| 2.10 | 空输入且在 live 位置时，观察输入框右上角；随后输入文字再观察                        | 显示 `down view agents`——**`down` 高亮**（leader 和弦期间保持 muted）、其余 muted；输入文字或翻历史即隐藏；行高占位不引起布局跳动 |
