# PR #60 跨模块边界回归（2026-11-21）

## 1. 现象与复现

基准为 2e3e35e0a9。真实请求中，A 是短文本、B 是带大图的未回答输入，单独 B 可以恢复，A+B 会在零次 provider 请求后退出。插件裁剪历史后返回 413 会读到越界下标。取消 Session 的旧任务收尾期间仍可启动新 shell。文件删掉最后一行时恢复遗漏，极短文件与 skill 可借标题超过预算。后台通知覆盖 default variant、启动回显超过工具预算、UTF-16 尾部截断可产生孤代理。MCP 异常响应与 Core 工具结果多附件可能丢掉有界错误或全文入口。

## 2. 根因

保留区、媒体选取和模型视图错误地共享了一个消息身份或数组下标。Session 取消先拍任务快照，后停生产者。恢复用文本子串表示文件版本、仅对正文收费。shell 回执和 MCP 异常没有统一经过输出限制。grep 的提前停止计数被显示成精确总数，POSIX 的反斜杠被当成目录分隔符。

## 3. 参考行为

以无额外前缀的同一媒体请求、正常用户输入/显式 variant、磁盘上当前文件的完整内容、最终输出估值、有限进程的退出状态与实际 rg 输出作为独立参照。契约见四组 feature 架构及已有 fix。CI 在同一历史上验证时还要区分子请求、摘要与父恢复请求。

## 4. 实施方案

- 请求恢复使用插件变换前的持久输入边界，预算及后续模型视图对同一待处理批次降级媒体，保持原 ID。自动压缩的额外原文受主模型 25% 及配置限制。恢复成功不发布终局错误，终局失败可观测。fork 映射有效样本，未被复制的样本丢弃。
- Session 停止涵盖停止期间本轮登记的 shell；正常 shell 语义允许程序主动脱离，保持既有前台 shell 的进程所有权边界。通知保留目标显式默认 variant。回执和缓冲尾部有界，返回合法 Unicode。
- 按文件身份和完整版本判重，按最终渲染开销约束恢复；todo 读取失败与空清单有别。
- grep 保留 lookahead，非末页报告下界，EOF 报告准确值；路径分隔遵从宿主。对 MCP 两种错误出口及摘要中的已有全文指针提供一致保护。
- CLI fixture 提供能容纳真实系统与工具的窗口，同时用模拟高 usage 触发原条件，按工作请求、摘要、通知区分调用；不放宽超时。

## 5. 正确性论证

原消息不变，模型视图的变换不能改变保护身份；估值和投影对同批媒体作相同处理。取消必须在该轮任务生产结束、已有任务结算后返回。文件恢复仅在同一原文件的完整可见内容匹配时省略；总输出预算必须涵盖随条目数增长的开销。grep 多取一条只证明还有下一条；读至 EOF 才能证明总量。一次最终成功和一次最终失败分别只应给 CLI 对应的退出状态。

## 6. 回归与性质测试计划

独立生成消息批次与媒体位置、插件裁剪、文件缩水/清空与异路径同内容、许多短材料和长引用名、取消与任务注册的交错、variant 和 Unicode 切点、grep 分页与文件名、MCP 错误形状与全文标签位置。测试读数据库、实际模型请求、CLI 退出状态、运行任务与最终输出。对照原失败 CLI 用例、受影响包、本地类型检查及远端 CI。
